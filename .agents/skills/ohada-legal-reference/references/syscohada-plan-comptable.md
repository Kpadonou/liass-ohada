# SYSCOHADA - Plan comptable OHADA

## Métadonnées

- Source : `syscohada-plan-comptable.pdf`
- Description : Plan des comptes SYSCOHADA extrait du PDF fourni
- Conversion : extraction texte PDF vers Markdown, avec séparation par pages.
- Usage : fichier de référence pour le skill Codex `ohada-legal-reference`.

## Avertissement d’usage

Ce fichier est destiné à servir de référence technique et documentaire à Codex pour le projet Liass-OHADA. Il ne remplace pas le texte officiel publié par l’OHADA. En cas de doute, vérifier la source officielle.

## Implications pour Liass-OHADA

- Utiliser les classes et libellés de comptes comme base de validation du plan comptable.
- Ne pas inventer de classes ou de comptes non présents dans la référence sans justification métier.
- Prévoir des extensions par entreprise sans altérer le référentiel SYSCOHADA de base.
