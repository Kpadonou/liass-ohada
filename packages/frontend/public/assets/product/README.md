# Public product screenshot slots

The public landing currently uses clearly labelled functional illustrations because the repository does not contain approved, anonymized product screenshots.

When real screenshots are available, use these slots:

- `cabinet-dashboard.webp` — Accounting Firm dashboard, 1600 × 1000 px.
- `accounting-overview.webp` — accounting overview or entries, 1600 × 1000 px.
- `treasury-reconciliation.webp` — treasury and bank reconciliation, 1600 × 1000 px.

Each image must come from the real application, use anonymized demo data, avoid personal or sensitive information, and include an AVIF alternative when the asset pipeline supports it. Keep the 8:5 aspect ratio so the current product frames do not shift during loading.
