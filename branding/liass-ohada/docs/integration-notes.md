# Quick integration notes

## Web
Use `web/html-snippets/head-tags.html` as a starting point for your `<head>`.

## PWA
Use `web/pwa/site.webmanifest` directly or adapt paths to your project structure.

## iOS
The `app-icons/ios` folder contains square PNGs ready for Xcode asset catalogs.

## Android
The `app-icons/android` folder contains launcher-style PNGs. Map them to your mipmap folders or Android Studio asset pipeline.

## macOS / Tauri / Electron
Use `app-icons/macos/Liass-OHADA.icns` when supported, or the 1024px PNG as source.
